# 💰 PocketSmart-AI
Your Smart Expense Tracker - Built with FastAPI & Python

🚀 **Live Demo:** https://pocketsmart-ai-oftr.onrender.com

### Features
- ✅ Add expenses with category
- ✅ Auto total calculation
- ✅ Local storage - data stays after refresh
- ✅ Clean UI - Mobile friendly
- ✅ FastAPI backend

### Tech Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Python FastAPI
- Hosting: Render + GitHub

### How to Use
1. Enter expense title (Tea, Bus fare)
2. Enter amount
3. Click Add Expense
4. See total below!
